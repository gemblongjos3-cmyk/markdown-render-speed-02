A from-scratch Markdown-to-HTML parser in a single dependency-free JavaScript file, byte-for-byte compatible with marked 18.1.3 (GFM) and optimized for CPU speed. It passes the full 720-case conformance set and three independently generated document sets, with the full-set parse time cut from about 3.9s to about 2.3s.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```

`node check-local.mjs` verifies the parser against the practice set.
